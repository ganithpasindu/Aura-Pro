# Changelog

All notable changes to **Aura Pro** are documented in this file.

## [1.0.0] - 2026-11-26
### Added
- Windows desktop app (`Aura Pro`) built with Rust and `egui` / `eframe`.
- 20 FPS screen capture and smooth UDP/Adalight streaming to ESP32.
- ESP32 Wi-Fi provisioning AP mode (`Aura Pro`), Wi-Fi scanning, and GPIO pin configuration.
- Per-LED position calibration and fullscreen white/color tuning (brightness, gamma, white balance, auto-start).
- System tray integration, single-instance protection, desktop app updater, and ESP32 GitHub OTA support.
